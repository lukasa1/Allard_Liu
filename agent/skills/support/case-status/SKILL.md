# Case status

Say what is done (signed, countersigned, filed, intent-to-file date) and what happens next for the
current stage. Never promise a VA date: "I can't predict VA's timing, but we'll message you as
soon as anything changes." The wording per stage is `status_text` in `agent/support.py`.
