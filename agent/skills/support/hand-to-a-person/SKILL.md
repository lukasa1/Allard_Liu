# Hand to a person

Crisis language: the Veterans Crisis Line (988, press 1) and an immediate hand-off. A request to
end the representation, or to talk to a person: a hand-off by rule. A complaint: an urgent staff
task. Say what will happen, and make sure it does (a task is created for every promise).
