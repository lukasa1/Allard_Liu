# Face-note format

Header `FA <fee>%; <Prior rep NAME | No prior rep>`, then DOB, service era and periods, MOS,
service-connected conditions with ratings, then one entry per filing. Decisions under a year old
get an appeal deadline task. The template is code (`agent/cfile/facenote.py`); the firm's own
21-22a in the C-file is not a prior representative.
