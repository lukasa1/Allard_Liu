# Intent to file (VA Form 21-0966)

Filed right after the countersigned 21-22a is submitted, before the C-file is requested: it holds
the veteran's potential start date for benefits for one year. With VA sign-in it goes through
Lighthouse Benefits Claims; otherwise staff file it by hand (a manual_filing task). If VA reports
an intent to file already active, its date is the one that protects the claim.
